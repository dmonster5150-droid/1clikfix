1ClikFix - Phase 1 (React + Vite + Tailwind + Firebase)

Setup:
1) Create a GitHub repo named `1clikfix` and paste each file above.
2) In Netlify, connect the repo. Build command: npm run build. Publish dir: dist.
3) Add environment variables in Netlify using `.env.example` names.
4) In Firebase, enable Authentication -> Google sign-in. Add Netlify site origin to Google Cloud OAuth origins.
5) Deploy and test.
